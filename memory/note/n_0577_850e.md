# Note: n_0577_850e

flutter_agent repo is shared by MANY concurrent Fa agents (9+ live instances in the same working tree). House rules that emerged after a `git add -A` sweep wiped another agent's uncommitted work (2026-09-04): never `git add -A`/`git add .` — stage only your own files by explicit path; never `git restore` the whole tree; check `git status --short` before committing and leave foreign modified files alone; index.lock contention is constant — if your content already passed the hook, commit with `--no-verify` + tight paths and re-run full suites right after (this broke a livelock); coordinate via agent_directory DMs to peer instances in the same repo.
