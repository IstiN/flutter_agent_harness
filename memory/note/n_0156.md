# Note: n_0156

The fa typing lag and cross-instance bash log garbage were both traced to an old pre-0.1.219 fa instance sharing the cwd; end-to-end typing-during-stream on the 0.1.219 binary measures p50 ~0.3ms (verified via tool/key_latency_probe.dart), so lag reports on new builds should be re-measured, not assumed.
