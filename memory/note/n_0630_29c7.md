# Note: n_0630_29c7

js_widget_runtime native router gotcha: live engines are keyed by JsRuntimeConfig.instanceId ?? widgetId in a process-wide route map. Hosts MUST pass a unique instanceId whenever several engines of the same app can coexist (tile + fullscreen + folder tiles): with a shared widgetId key, the last registration wins and ANY engine's dispose removes the shared route, so the surviving engine's render/storage/interval messages drop as "(engine gone)" — UI frozen, taps silently dead. flutter_app JsAppEngine passes its per-instance id since f4159fad.
