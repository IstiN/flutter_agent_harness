# Note: n_0658_06d2

MV3 constraints for the extension: CSP cannot use sha256 hashes (inline scripts must be external files), wasm needs 'wasm-unsafe-eval'; canvaskit must be served locally from ./canvaskit/<rev>/chromium/ (script mirrors flutter's flat layout into revision dirs), and PWA must be disabled (--pwa-strategy=none) to avoid flutter's runtime service-worker inline-script injection.
