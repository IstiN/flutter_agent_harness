# Note: n_0720_f7e7

Extension approval flow (fixed in 823cf529): the SW approval-mode change applies LIVE mid-run (reconfigure no longer drops it behind the busy guard) and flipping to yolo/unattended resolves pending prompts as allowed; chat surfaces (session sheet via fa_ui FaChatSurfaceHandlers) install approval/ask/secret handlers, so approvals are answerable in the panel. The 120s timeout deny remains only the backstop when no client can answer. Supersedes the old 'stay silent, 120s is the only backstop' policy note.
