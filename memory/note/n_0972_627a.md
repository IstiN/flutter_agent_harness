# Note: n_0972_627a

The ai/gh-* job branches on this repo are subject to a background machine merge-loop that can squash-rewrite history (single root commit like 207a4988 "--quiet (#641)") and RESET the worktree, silently discarding UNCOMMITTED changes — outputs/, input/, and worktree edits included. Commit work early and often (explicit git add of only your files — pre-staged environment deletions can otherwise get swept into your commit), and re-check `git status`/`git log` before writing outputs/. The runner's CodeGraph indexer and test suites may also delete/regenerate tracked files (e.g. test/integration/screenshots/*.png) mid-run — restore from HEAD after runs.
