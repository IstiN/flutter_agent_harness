# Note: n_0824_c142

Extension of the standing review rule (user directive): not only PRs — OPEN ISSUES/goals must also be periodically audited against their ORIGINAL goal text. On every monitoring cycle: for each open issue, check remaining ACs against the original description (not against later PR-scoped reinterpretations), detect silent scope drift (ACs quietly abandoned or redefined downward), and report a per-issue ledger (done / remaining / needs-owner-verification). Never close an issue on PR-body claims alone — only on original-AC evidence plus owner acceptance for manual items.
