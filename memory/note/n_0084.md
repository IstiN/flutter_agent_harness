# Note: n_0084

In the flutter_agent_perf_tui worktree a rogue process (likely stale-buffer IDE) reverts uncommitted edits within seconds and even deletes .fah log files; countermeasure: apply all edits in one atomic batch and commit instantly (<1s) or run checks in a temporary fresh-clone worktree, and never trust bash-channel stdout — verify file content only via the read channel.
