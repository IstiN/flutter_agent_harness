# Note: n_1001_5ff8

This fa runner prepends a git wrapper to PATH (~/work/_temp/git-push-guard-bin/git). Code needing the REAL git must resolve it with `command -v -p git` (system PATH) — plain `command -v git` returns the wrapper. A PATH-shim selftest (fault-injecting `git` on PATH) that execs the wrapper ping-pongs with it and spins forever; exec the real binary.
