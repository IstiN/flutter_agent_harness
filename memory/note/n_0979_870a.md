# Note: n_0979_870a

curl's internal `--retry N` does NOT resume with `-C -`: on a timed-out attempt it starts over from offset 0, truncating the partial output (verified locally against a throttling range server — transfer restarted at 0 with `--retry 2 -C - --max-time 2`). To make a bounded, resumable download, own the retries in a bash loop and give curl only `-C - --max-time <budget>`; `rm -f` the partial file before the loop so `-C -` resumes only your own bytes. Budget arithmetic for GH Actions: attempts*max_time + (attempts-1)*sleep must fit the step's timeout-minutes (remember curl `--retry N` means N retries PLUS the initial attempt).
