# Note: n_0354

sha256-mismatch install failure (2026-08-30): ROOT CAUSE — fa_widgets zips were non-deterministic (ArchiveFile.lastModTime defaulted to wall-clock); every publish run --clobber-replaced ALL release zips with new bytes/hashes, while apps hold a TTL-cached catalog.json → cached hash ≠ current zip → 'zip sha256 mismatch'. FIXES: (1) fa_widgets@ed4d282 — canonicalZipTimestamp 315532800 (1980-01-01) stamped on every zip entry in catalog_builder._writeZip + determinism test; rebuilds over unchanged sources are now byte-identical. (2) flutter_agent@f2ef2c84 — CatalogService.downloadWidgetHealing: on sha-mismatch refetch catalog (force, bypass TTL) and retry ONCE with the fresh entry (only if entry changed); wired into WidgetsCatalogSheet._install and apps_catalog_tool. Old-version zips survive on the release (upload --clobber only replaces same-named assets), so version bumps never mismatched — only same-version rebuilds did.
