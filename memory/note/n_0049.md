# Note: n_0049

After any attach/messaging code change, the fa CLI (~/.local/bin/fa) and Fa.app (flutter_app) must both be rebuilt and restarted with matching versions, otherwise their storage roots and mailboxes split again; running sessions must be restarted to pick up new binaries.
