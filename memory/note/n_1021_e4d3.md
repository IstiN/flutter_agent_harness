# Note: n_1021_e4d3

UI layout and geometry must be invariant across all visual themes/directions and across Chats/Activity/Apps at the same viewport: only colors/material/blur may differ. Do not maintain separate glass vs non-glass layouts or per-section copies of shared chrome; use one shared implementation (e.g. MessengerSectionHeader) and widget tests that compare geometry across themes/sections.
