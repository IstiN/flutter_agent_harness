# Note: n_0985_fd62

flutter_app `flutter test` needs two gitignored placeholders before it builds: (1) `flutter_app/.env` — declared as a pubspec asset, MUST have content (printf 'OPENROUTER_API_KEY=\nMODEL_ID=\nBASE_URL=\nHUGGINGFACE_TOKEN=\n'); bare `touch .env` still fails with "No file or variants found for asset: .env" on flutter 3.47.x (documented in ci.yml ~:1059). (2) `flutter_app/lib/firebase_options.dart` — copy from firebase_options.template.dart. Mirror of the CI "Create placeholder .env asset" steps. Also: `dart format` reports false "changed" for flutter_app files when run before `flutter pub get` (package resolution warning poisons the check) — run pub get in both root and flutter_app first.
