# Note: n_0482_c746

Per-folder model memory shipped in fa 0.1.281 (commit c9d40ceb): /model and /provider switches save provider+model+baseUrl to <sessionsRoot>/<encodeSessionCwd(cwd)>/model-state.json (folder_model_state.dart); boot restores it unless --model/--provider/--base-url or FA_PROVIDER_* preconfig pin the launch. The global ~/.fah/config.yaml provider/model triple is now a FROZEN SEED (persistConfig writes saved.* back) — switches never leak across folders. onModelChanged/onProviderChanged are Future<void> and awaited everywhere (fire-and-forget lost switches on quick /exit). Over-window guard renders a calm yellow note + guidance instead of a red error.
