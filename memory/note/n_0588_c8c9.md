# Note: n_0588_c8c9

Release pipeline gotcha (fixed 2026-09-05): pub.dev publishes were silently dead for ~80 releases (v0.1.214..v0.1.293 never published, pub.dev stayed at 0.1.213) because the CI tag run's quality gates kept failing on the flaky test/cli/tui_prototype_snapshot_test.dart (real PTY + `dart run` cold start exceeded 5s waits on CI runners), and the publish job needs quality to pass. Fix: the test is now @Tags(['integration']) + 20s waits; AWS key fixtures in test/redact/layer_vendor_test.dart are split literals ('AKIA'+'...') because pub.dev's publish scanner rejects key-shaped literals in the package. Check pub.dev via the packages API, not just tags: tags can exist without publishes.
