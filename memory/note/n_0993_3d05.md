# Note: n_0993_3d05

The fa-story-dev / rework checkout of flutter_agent_harness runs an ambient WIP auto-save that commits ALL working-tree changes to the current branch every 5 minutes ("gh-XXXX WIP auto-save <timestamp>" commits). Scratch files left in the repo root get committed too — clean them up before finishing, and never rely on `git diff HEAD` showing your edits (compare against the pre-task merge base with origin/main instead, e.g. `git diff <merge-base> -- <paths>`).
