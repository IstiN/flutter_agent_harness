# Note: n_0977_37aa

flutter_app full suite on macOS: run `ulimit -n 10240 && flutter test --coverage --concurrency=4` — at default fd limit / high concurrency it fails with "Too many open files" or hangs silently at 0% CPU with empty output; never pipe through `tail` (buffers the whole run). CRAP ladder measurement: `cd flutter_app && flutter test --coverage && dart pub global run crap4dart analyze`; threshold in flutter_app/crap4dart.yaml only moves DOWN to the measured worst (scripts/check_crap_guards.py enforces).
