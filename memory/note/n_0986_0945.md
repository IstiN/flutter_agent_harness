# Note: n_0986_0945

Repo convention (gh-1199, 2026-10-04): the merge-blocking Quality gate is deterministic-only — every live-provider test carries @Tags(['integration','llm']) and is excluded from per-PR legs twice (shard_files.py --exclude-tag llm at selection, --exclude-tags llm at invocation). scripts/check_llm_tag_boundary.py (static gate + test/scripts/llm_tag_boundary_test.dart) fails any integration-tagged file that looks live without the tag; AUDIT_MOCK pins justified exceptions. Flake quarantine: scripts/test_quarantine.json + apply_quarantine.py (gate legs filter through it; nightly deliberately does NOT, to produce un-quarantine proof); flake-watch.yml hourly auto-files flake issues + quarantine PRs on >=2 distinct-SHA reds in 24h. Live verification belongs to nightly / tag-only provider smoke / supervised benches, never the PR path.
