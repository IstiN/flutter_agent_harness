# Note: n_0729_0c45

Browser-ext CodeMie cookie auth: the SW fetch client must use credentials:'include' (browser attaches the jar; MV3 + <all_urls> host permissions = no CORS) because setting a Cookie header on fetch is a forbidden-header no-op. Panel-only host capabilities (cookies.get_all / SW fetch / tabs.create) ride the ext_request/ext_result FaUiProtocol kinds; dispatch is pure in browser_ext/dart/src/ext_ops.dart. A CodeMie base URL (isCookieAuthUrl in providers.dart) must bypass the bridge relay in resolveStreamFn — the relay strips cookies and CodeMie 401s.
