# Note: n_0649_d357

Cross-agent git hygiene: a second fa agent committing in ~/git/flutter_agent may sweep (revert) OTHER agents' uncommitted lib/ edits (observed: widgets agent's commit restored file_messaging_repository.dart to HEAD). Rule: commit small and immediately after tests pass; never leave lib/ changes uncommitted while another agent works in the same worktree.
