# Note: n_0206

fa v0.1.236 (chain running): (1) THE THINKING-FREEZE ROOT CAUSE: a streamed paragraph with NO newline grows its last line; sync() re-formats + re-wraps the WHOLE line on every 16ms flush — O(line length) per tick; a 45KB thinking burst = hundreds of ms per flush = event-loop starvation = screen frozen (neither thinking NOR typed input visible). FIX: growing-tail throttle in TranscriptMarkdown.sync — when the only pending change is one line >8192 chars (src.length == _through+1), re-render at most every 100ms (~10Hz), immediate on final newline; debugTailThrottled counter; byte-exact tests unaffected. NOTE: single-element src lists (src.first IS the growing line) take the _rebuild path (identical-sentinel fails) — throttle still applies (checked src.length==_through+1 AFTER rollback where _through=0). (2) codemie keyName: SURGICAL _scopedKeyNameForNonDefault(provider, baseUrl) (host-scoped FA_KEY_<HOST> for non-catalog-default endpoints, null otherwise) used ONLY at the two model-switch pin sites (provider_models 662/737) — the /provider CONNECT flow keeps asking for keys (roles tests caught my first attempt touching _rolesKeyNameFor broadly: preservedName became FA_KEY_PROXY_TEST_1 → applyToAgent ConfigException). Token expiry → silent browser re-auth exists via _handleRunError→_maybeHandleCodeMieError→_handleCodeMieAuthExpired (marker-based, path-independent). SSO wait: 5min timeout + 15s live status (waitForToken had NO timeout). (3) Status bar: price hidden when cost==0, _formatTokenCount for total tokens, 'provider/model' in status line (test agent_cli_test.dart:1562 updated keeping $0.0010 since that fixture has real cost). User requirements: NO token switching — only the entry's OWN key + refresh.
