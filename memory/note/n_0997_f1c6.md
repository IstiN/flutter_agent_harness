# Note: n_0997_f1c6

flutter_agent_harness gotcha (gh-1577 rework, pr-1582): the agent loop consumes the AssistantMessage's OWN stopReason — DoneEvent.reason is never merged into the message (DoneEvent.partial => message). Scripted provider turns that model "length"-flagged or otherwise cut-off completions must set stopReason on the MESSAGE (testAssistant(stopReason: StopReason.length)), not just DoneEvent(reason: length). Several pre-existing fixtures (agent_loop_test.dart lengthEmptyTurn, agent_cli_empty_completion_hiccup_test.dart REG-2 lengthEmpty) had it wrong and were silently exercising clean-stop empties. Also: AssistantMessageEventStream consumers return at the terminal event (DoneEvent/ErrorEvent) WITHOUT waiting for stream.end() — holding end() does not hold a scripted request in flight; to model a cancel-racing-request, serve only a non-terminal StartEvent and push the terminal from cancelToken.onCancel.
