# Note: n_0303

Multi-account support in fa provider integrations:
- Copilot: first-class multi-account in BOTH CLI and flutter app. Per-entry-scoped key FA_KEY_COPILOT_<SANITIZED_NAME>. CLI has 'add another account' picker; flutter app: runCopilotConnectFlow matches by name+endpoint, comment says 'Multiple accounts are first-class, like the CLI'. No cross-account fallback.
- Codex/ChatGPT: SINGLETON only - CLI uses single key CHATGPT_OAUTH_CREDENTIALS (overwrites on every OAuth), flutter app hardcodes const name = 'ChatGPT', matches by baseUrl only. By design (one OpenAI account per user). Adding more ChatGPT accounts is NOT supported. To change: introduce CHATGPT_OAUTH_CREDENTIALS_<NAME> key scheme like Copilot's FA_KEY_COPILOT_<NAME>.

Code paths verified on 2026-08-29: PR #1 head 7a4f2201, PR #2 head 45efd8a6.
