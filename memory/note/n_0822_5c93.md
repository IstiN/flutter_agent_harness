# Note: n_0822_5c93

Standing review rule (user directive): every PR review MUST compare the delivered work against the ORIGINAL issue description / GOAL card acceptance criteria — not against the PR body's own claims. Review-agent tasks must always include the issue body (gh issue view N) and check each original AC item-by-item: met / partially met / silently dropped. A PR that redefines scope downward without saying so is request-changes even when its own description is fully delivered. Also verify the issue's stated problem would actually be reproduced without the fix (red-test check), not just that the PR's narrow interpretation is covered.
