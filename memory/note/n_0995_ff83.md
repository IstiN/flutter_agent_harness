# Note: n_0995_ff83

`dart test` (full suite) cannot complete in the CI runner environment: the Dart VM deterministically core-dumps with a glibc malloc error ("malloc_consolidate(): invalid chunk size" / "unaligned tcache/fastbin chunk") right after `test/cli/tui_prototype_snapshot_test.dart: ctrl+s submits when enter is used for newline` — the tui_repl/PTY test family corrupts native heap. Pre-existing: reproduces identically on base commit 2dfc613 and when running `dart test test/cli/` alone. To verify "no regressions" on a full-suite scale, run `dart test` (verifies everything lexically up to test/cli/) plus a second run of `ls test/*.dart | awk '$1 > "cli"'` and `ls -d test/*/ | awk '$1 > "cli"'` for the remainder.
