# Note: n_0731_5f0b

MV3 extension SSO constraints: the service worker has no webview, and IdPs like CodeMie SSO send X-Frame-Options DENY so iframe login is impossible; login opens a normal tab sharing the extension cookie jar, and fetch with credentials:'include' carries cookies since Cookie is a forbidden fetch header.
