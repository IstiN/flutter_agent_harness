# Note: n_0983_5205

gh-1054 rework environment: the WIP auto-save bot commits and pushes ALL working-tree changes every ~5 minutes (commit message 'gh-1054 WIP auto-save <timestamp>'), including mid-round lib changes. So mid-round `git status` can look clean while the work sits in a local auto-save commit — check `git log` before assuming edits are lost, and just keep working; the final push carries everything. Also: its merges of origin/main have repeatedly reverted one side of PR-touched files (rounds 1-2 dropped issue #862 wiring); after EVERY bot merge commit lands, re-verify `git diff origin/main HEAD` for the PR-touched files before building on them.
