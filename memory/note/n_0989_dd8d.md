# Note: n_0989_dd8d

Conveyor wedge on release PRs: if SM update-branch pushes a new head AFTER ai_validated was stamped, the ruleset's 3 required ci.yml checks (Quality gate, Binaries smoke gate, JS engine integration) are missing on the new head — the SM validation lane (~4 min) does NOT run ci.yml, labels are terminal so no lane re-fires, mergeState stays BLOCKED forever. Unblock: manual `gh workflow run ci.yml --ref <release-branch>` on the exact head; merge bot merges on next tick once green.
