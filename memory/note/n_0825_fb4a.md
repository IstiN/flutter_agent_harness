# Note: n_0825_fb4a

В flutter_agent TUI-режиме весь вывод плагинов должен идти через TUI-обёрнутое поле this.io (PluginContext), а не через сырой конструкторский io — иначе writeln обходит очередь рендера и текст попадает в зону композера.
