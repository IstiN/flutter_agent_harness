# Note: n_0990_be13

Pushing branches that touch .github/workflows/* fails with "refusing to allow an OAuth App ... without workflow scope" because the default git credential resolves to the keyring IstiN token (scopes: repo, NO workflow). The env GH_TOKEN (account ai-teammate) HAS workflow scope — push with: git -c credential.helper= -c credential.helper='!f() { echo username=x-access-token; echo [REDACTED_SECRET] }; f' push. Plain pushes (no workflow files) work with the default credential.
