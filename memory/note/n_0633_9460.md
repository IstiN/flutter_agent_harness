# Note: n_0633_9460

Widget state-sync protocol: sibling JsAppEngine instances of one app share state via storage.json plus a reserved `state.sync` broadcast event; widgets persist {v, rev, writer, mode, running, remaining, endsAt, completed} under reserved key `__state`, with wall-clock endsAt as countdown truth (no per-second sync); doc at fa_widgets/docs/state-sync.md.
