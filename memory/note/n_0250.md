# Note: n_0250

fa v0.1.241 — pushed as commit 0f9f1c02 on origin/main. Three pieces: (1) Remote models catalog at fa1.dev/models-catalog.json — preload once per process via RemoteCatalogEnrichment (lib/src/providers/), fills contextWindow defaults for endpoints that don't publish them (MiniMax M3=1M, M2.x=204800) and ships per-slot media lists (image/video/tts/asr). The catalog NEVER seeds chat ids — endpoint /v1/models is the source of truth; catalog only enriches metadata + media. (2) Thinking deltas in TUI now apply inline markdown (bold/italic/code) before dim wrapper via renderInlineMarkdown + per-marker _matchInline* helpers. (3) AnsiMarkdown._renderTableRows split into _tableFragments/_tableSeparator/_renderTableRow/_renderTableLine — CRAP 16.27→12.00, coverage 69%→100%. All gates green: 21 new tests (16 catalog + 5 inline markdown), 3102 core green, coverage 91.42%, CRAP max 12.00, format self-heal OK. Released install fa 0.1.241. Rebase dance: chore(release) v0.1.241 landed first, my commit rebased on top clean (no conflicts because they only bumped CHANGELOG/pubspec and my feature commit replaced both).

Critical lesson: when user says "не хардкодь текстовые модели" — they mean chat ids must come from /v1/models only, not from catalog contextWindows keys or defaultModelId. The catalog is metadata-only for chat; media slots are seeded from catalog.media because the chat endpoint never returns them.

Critical lesson: stash-merge from same branch with both unstaged local changes + uncommitted same-file edits leaves merge-conflict markers in the file even after rebase resolution. When that happens, the safe path is git reset HEAD -- <files> + git checkout HEAD -- <files> + rm untracked <files>, then re-apply work cleanly. Python str.replace silent no-ops in conflict-marker scans are the biggest landmine — verify with grep before assuming the file is clean.

Critical lesson: AnsiMarkdown._renderTableRows was a pre-existing CRAP ratchet violation (CC=12, cov=69%, CRAP=16.27). To fix without touching public behavior, split the single dense method into 4 single-purpose helpers: _tableFragments (pre-wrap + heights), _tableSeparator (dim grid line), _renderTableRow (loop outer rows), _renderTableLine (one physical line of cells). Each helper is now CC≤3, CRAP≤12 at 100% cov.
