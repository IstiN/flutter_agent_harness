# Note: n_0817_3b5c

Shift+Enter bug root cause (#77): fa never sets true raw mode — dart_tui only touches ICANON/ECHO, fa stty only IXON, so ICRNL stays on and the kernel rewrites CR→LF; yoloit sends ESC CR which arrives as ESC LF, and the parser maps bare LF to enter, ESC CR to alt+enter, but ESC LF to unknown = silent no-op; fix is set -icrnl at TUI start plus decode ESC LF as alt+enter.
