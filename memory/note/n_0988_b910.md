# Note: n_0988_b910

auto_release.sh rejection memory: a CLOSED (unmerged) PR from branch chore/release-vX.Y.Z blocks all future auto-release runs for that version ("machine rejection, human decision required") until the tag exists. To regenerate such a release: delete the closed PR's branch is not enough — recreate the bump manually (fresh clone, bump pubspec + flutter_app/pubspec lockstep, full vLAST..main changelog, commit as github-actions[bot], push branch, open PR). Also: auto_release.sh appends a fresh '## Unreleased' section every run (stacking duplicates), and computes the changelog from the latest TAG — a stray lightweight tag on a non-release commit silently shrinks the changelog and wedges the release PR in review loop.
