# Note: n_0411

TUI changes in flutter_agent must be tested with the PTY integration tests, not only unit tests: harness test/integration/pty_harness.dart + fa_cli_integration_test.dart (dart test --tags integration), and VISUAL screenshot tests in flutter_app/test/cli_visual/fa_cli_visual_test.dart (run: cd flutter_app && flutter test test/cli_visual --tags integration) which render PNG+.txt twins into test/integration/screenshots/NN_name.{png,txt}. Pattern: boot() → runSlashCommand('/x') → liveWaitForText('...') → screenshot(shotsDir, 'NN_name') → sendEnter()/arrow keys. Always override HOME with a temp dir with minimal .fah/config.yaml; approvalMode: yolo. User explicitly asked to always cover TUI flows this way (after the Add-provider→Copilot flow bug that unit tests missed).
