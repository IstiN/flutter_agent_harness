# Note: n_0987_a4f1

flutter_app iOS/macOS Podfile.lock regeneration works on Linux (no macOS needed): (1) cd flutter_app && flutter pub get --enforce-lockfile + flutter precache --ios/--macos (podhelper needs Generated.xcconfig + Flutter.podspec); (2) stage WasmRun.xcframework into vendor/wasm_run_flutter/{ios,macos}/Frameworks (upstream zip or scripts/setup_vendor_ios.sh) — the Podfile post_install raises without it; (3) the post_install runs `nm -gU -arch arm64` on a Mach-O archive — GNU binutils nm cannot read Mach-O, so shim PATH with llvm-nm (wrapper script exec llvm-nm-18); (4) gem install cocoapods (pure-ruby, no sudo) then pod install --repo-update in ios/ and macos/. SPM is disabled for both platforms (swift_package_manager_enabled false in .flutter-plugins-dependencies), so every native plugin rides pods. Guarded by scripts/check_lockfiles.sh (gh-1296).
