# Note: n_0989_4022

gh-1300 (shipped): PTY/CLI integration tests run the CLI through the FA_BIN AOT seam — every fa spawn site (FaCliHarness.spawn + the headless helpers) resolves via `faCliCommand()` in test/integration/pty_harness.dart: explicit extraEnv FA_BIN > ambient FA_BIN env > the site's original JIT `dart` prefix. CI compiles the bundle ONCE per run (ci.yml `fa-aot-build` job, arm64, artifact relay to the 3 shards; nightly builds in-job) and exports FA_BIN, so per-test spawn drops from ~30s (VM+CFE on loaded ARM runners; ~8.6s warm local) to <0.1s. Measured locally: composer_echo file 39s->20s, `dart bin/fah.dart --version` 8.6s vs binary 0.01s. NOTE: `dart compile exe` refuses this repo (sqlite3 hooks) but `dart build cli --target=bin/fah.dart --output=fa-local` WORKS (write version.txt into bundle/ after, or --version reports the 0.1.0 fallback). The per-shard duration-budget ratchet (scripts/check_shard_durations.py + test_shard_budgets.json, seeded 420s/shard pending post-seam tightening) fails the gate on breach and auto-files the [ENH] duration-budget-labelled issue; selftest scripts/duration_budget_selftest.sh runs in the ci.yml guards leg. Boot-timeout band-aids (waitForBoot 300s/5min in 5 files) were removed back to the 90s default. Local dev box caveat: the fa agent sandbox exports FA_PROVIDERS_QUEUE/FA_PROVIDER_*/FA_LOG_FILE etc.; headless spawn tests that do NOT scrub the parent env (headless_log_file, backend_mode, ctrl_c) fail LOCALLY with those set — pre-existing env noise, identical on the pristine base commit; scrub the FA_* vars (or run on CI) before debugging them.
