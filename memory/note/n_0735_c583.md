# Note: n_0735_c583

In browser_ext: chrome.tabs.create/tabs.update resolve BEFORE the page finishes loading, and SPA navigations (Google results, pushState) fire webNavigation.onHistoryStateUpdated, NOT onCompleted — nav_wait therefore checks the tab's current status/url first and rides both event streams; waiting only for the next onCompleted produces false timeouts against already-loaded pages. Also: MV3 chrome.notifications.create requires iconUrl for type:'basic' (missing icon invalidates the whole options object with a misleading "required properties missing" error).
