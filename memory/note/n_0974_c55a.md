# Note: n_0974_c55a

PTY-test forensic for tall composers in the fa TUI (issue #503): on a raw PTY a LF byte SUBMITS the composer line (busy → enqueues it) — sendText('a\nb') does NOT build multi-row input; it queues. To build a genuinely TALL multi-row composer, send ctrl+o ('\x0f') per newline (fallback newline-insertion key; shift+enter/alt+enter also map). Driving 39 ctrl+o + text reproduces the frame-overrun shape deterministically (was RED at 100x40 AND 80x24). Also: resume boot marker for PTY tests — ' · ctx ' (the status row) survives any flood; '[Model]' (banner) scrolls off a flooded 24-row glass and times out waitForBoot.
