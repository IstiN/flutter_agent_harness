# Note: n_0772_ae18

`gh pr checks` can transiently list only CodeQL/Analyze while ci.yml and browser-ext.yml runs are still queued — a "no pending" watcher then merges too early or fails. Watchers must wait until the required checks (Quality gates, Headless Chrome suite, CodeQL) APPEAR and pass, not just for "pending" to vanish.
