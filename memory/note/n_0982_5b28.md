# Note: n_0982_5b28

To replicate CI's CRAP ratchet locally: dart test --coverage=coverage --exclude-tags integration (full suite), then dart test --tags integration --coverage=coverage test/cli/jsr_cli_test.dart test/cli/cli_args_jsr_test.dart test/cli/agent_cli_jsr_test.dart (CI folds these into shard-0 coverage; without them jsr_cli.dart shows 0% and false-fails at CRAP 110), then dart pub run coverage:format_coverage --lcov --packages=.dart_tool/package_config.json -i coverage -o coverage/lcov.info --report-on lib,bin, then dart pub global run crap4dart analyze (pin >=0.11.0 <0.12.0). Ratchet is 12.0 only-down: a function pushed to CC 13 can never pass (min CRAP at 100% cov = 13) — extract a helper instead; never bump the threshold.
