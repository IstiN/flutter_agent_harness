# Note: n_1000_2c74

gh-1630: the extension vendors ALL engines locally (browser_ext/vendor.lock.json + scripts/fetch_vendor_assets.sh, sha-256-pinned) — the panel's on-device engines (webllm/transformers/litert) load via vendor_loader_*.js staged by scripts/stage_extension_panel.py, and the run_script interpreters resolve through flutter_app/lib/sandbox/web_interpreters_urls.dart (--dart-define=FA_HOST=extension compiles package-relative ../../vendor/ paths; the CDN constants are tree-shaken out of the bundle). No jsdelivr anywhere in the package — remote-code markers are scanned byte-wise by scripts/ext_package_guard.py check and scripts/check_cws_compliance.py on every PR (REG-1, .github/workflows/browser-ext.yml).
