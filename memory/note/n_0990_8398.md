# Note: n_0990_8398

flutter_agent_harness CI: the three required PR checks ("Quality gate", "JS engine integration (quickjs-ng)", "Binaries smoke gate") can all show "failure" from ONE root cause: machine-sm.yml stamps all three contexts (bridge-free factory #510, validation-checks input) with the validation verdict, and js-ext/binary jobs `needs: quality-gate` so they skip (never run) when the gate is red. Diagnose the real failure via `gh run view <run-id> --json jobs` — only jobs with a real conclusion matter; instant 1-second check-runs are SM stamps. Known transient-infra red class: `Failed to FinalizeArtifact: ECONNRESET` on actions/upload-artifact after green tests fails the whole pty-integration shard; hardened in gh-1412 with one-shot overwrite:true retry steps (guarded by test/ci_pty_artifact_upload_retry_guard_test.dart, gh-1310 precedent).
