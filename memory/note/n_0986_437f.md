# Note: n_0986_437f

Fresh git worktrees of flutter_agent_harness fail the pre-commit analyze gate (tens of thousands of phantom errors like uri_does_not_exist) until `dart pub get` is run in the root AND every subpackage: browser_ext/dart, office_addin/dart, packages/* (dap_hub, fa_llm, fa_llm_mock, fa_ui, fa_widgets). Always pub-get a new worktree before committing.
