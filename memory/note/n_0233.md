# Note: n_0233

fa 0.1.240 shipped (commit 0dc54496 on origin/main, installed): compaction-hang fix. Root cause of the ~58-min 'Compacting context…' spinner: a summarizer endpoint that accepts the request and never answers pends stream.result forever — provider connect/idle watchdogs (180s/5min) miss dribbling keep-alives and lost completions. Fix: AutoCompactor gained attemptBudget (default 10 min, ctor param) — every compactSession() attempt runs under Future.timeout; TimeoutException is non-transient (no retry spin), the pass falls to the next summarizer or the honest local trim, turn continues. Bonus fix found by the new test: the emergency local trim now zeroes kept AssistantMessage usage anchors (a stale generation-time anchor kept the post-trim estimate over the window and retriggered compaction every turn — same rule as the success pass). Two tests with a never-completing Completer summarizer drive both paths (rescue-via-trim, honest-failure-when-nothing-to-trim). Note: user's live hung session needs kill + `fa --session <id>` resume; new fa prevents recurrence. Push needed rebase (other agents pushed chore(release): v0.1.240 — landed cleanly).
