# Note: n_0412

fa1.dev widget preview contract: catalog.json carries per-widget preview{manifest,js} raw URLs (vendored → flutter_js_widget_runtime@pinned-sha, local → fa_widgets main); the gallery passes them to the jsr preview runner as ?manifest=&js= query params (runner falls back to its fa_widgets-raw convention). raw.githubusercontent.com caches ~5min — verify prod catalog via `git show origin/main:catalog.json`, not curl.
