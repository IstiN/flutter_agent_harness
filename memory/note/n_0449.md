# Note: n_0449

jsr web bridge architecture: widget JS runs in a Worker (no navigator.mediaDevices etc.), so web bridges are built on the generic jsr.hostCall(name, args) channel (bootstrap __jsr_host_call → __jsr_resolve round trip, JsRuntimeConfig.onHostCall, all three engines). Thin JS shim + main-thread Dart handler (e.g. example/lib/web_asr_handler.dart for mic). Null handler rejects 'hostCall is not supported'. Fa app web builds should use the same pattern for jsr.fa.* bridges.
