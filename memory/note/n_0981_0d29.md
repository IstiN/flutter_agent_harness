# Note: n_0981_0d29

Owner's surfacing rule for the capability-matrix architecture (2026-09-29, issue #1079): a capability unavailable on a platform must HIDE in that host's UI (menus, settings, slash commands, tool palettes) AND in model-facing prompts (tool schemas, system-prompt sections, skills listings) — hiding is bidirectional (CLI also hides browser-API capabilities). The card implementing the builder must also update AGENTS.md + relevant host-development skill(s) with these capability rules for future work.
