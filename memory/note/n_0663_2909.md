# Note: n_0663_2909

Browser-ext panel self-test: scripts/check_extension_panel.dart reads the panel's console via CDP (Dart WebSocket), so page errors no longer need the user to relay output. Two Chrome facts behind it: (1) branded Google Chrome >= 137 silently ignores --load-extension — must use Chrome for Testing (auto-provisioned to ~/.cache/fa-chrome-for-testing); (2) the unpacked extension id comes from the manifest 'key' (sha256 → a-p hex mapping), not the load path. CfT download: https://storage.googleapis.com/chrome-for-testing-public/<ver>/mac-arm64/chrome-mac-arm64.zip (~180MB), then xattr -dr com.apple.quarantine.
