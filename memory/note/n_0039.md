# Note: n_0039

CORRECTION to the interactive file-reference feature (Aug 26): resolveInteractiveFileReference NEVER inlines content — user explicitly rejected auto-inlining (a pasted path may be a huge log; inlining would blow context before anyone looked). Behavior: first path-like token (/…, ~/, ./, ../) that exists → '[attached file: <abs> — read it with your tools]' reference + trailing input as instruction; the LLM decides itself whether/how much to read via its read tool (line-range selectors). Installed in fa 0.1.210. Tests: test/cli/interactive_file_reference_test.dart (+10). Headless (.md/.txt inline there) intentionally unchanged — documented GOAL.md behavior.
