# Note: n_1008_0b07

flutter_agent_harness: `fa <subcommand>` (session/clean/list/repair, trajectory, config, ...) must be the FIRST CLI token — global flags like --session-root cannot precede the subcommand (parseCliArgs dispatches on args.first; anything after a global flag becomes a positional prompt and trailing flags error with "unknown argument"). Subcommand-specific roots default to $HOME/.fah/sessions; test CLIs against a fake HOME.
