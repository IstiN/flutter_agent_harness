# Note: n_0732_82e2

flutter_agent browser-extension build artifacts (e.g. sw/agent.js) are not committed to git, so after source fixes the bundle must be rebuilt with scripts/build_browser_ext.sh --with-app and the extension reloaded in chrome://extensions.
