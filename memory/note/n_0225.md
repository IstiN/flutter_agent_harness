# Note: n_0225

fa CRAP-ratchet round (main checkout): the pre-commit hook NEVER ran in the /tmp clone (.git/hooks/pre-commit not installed there) — all clone-era commits bypassed analyze/tests/coverage/CRAP. The first real gate run on main caught: (1) stale locks (memory 0.0.6 void deleteRecord; app resolved harness 0.1.218); (2) app wiring gaps (0.1.239 fixed); (3) CRAP > 12 on EIGHT methods from the perf sprint: sendBusy 30 (fa_tui), _AutoCompactorCliHooks.onDelta 20, _switchCrossProviderModel 20, _closeDanglingFence 20, renderSystemNoticeLines 18.09, TranscriptMarkdown.sync 13, replayLines 12.14, replayLinesTui 12.03. ALL fixed by pure extractions (CC is what matters at ~0 coverage: CC≤3 → CRAP≤12; at 100% cov CC≤12): sendBusy = math.max clamp + busy-EDGE send (semantics preserved: only 0→1/1→0 edges reach BusyMsg); _rollingTail; _maybeSwitchToSavedEntry; fold-XOR fence scan; _needsRewrite/_isServiceLine/_nextOpenTag/_taskOpenerEnd; _resumable/_tailThrottled (sync CC 13→6, throttle decision byte-identical short-circuit); _replayUserTui/_chromeMarkerLine. GOTCHAS learned: (a) crap4dart N/A-coverage methods default CRAP to comp²+comp (CC5 → 30); (b) single-line `=> 'literal'` getters DO get coverage lines normally (the ABSENT-line scare was a bad manual lcov parse — block-body conversion unnecessary, kept anyway harmless in providers/site_handlers/types); (c) `dart test --coverage` is INVALID — must be `dart test --coverage=coverage --exclude-tags integration` then `dart run coverage:format_coverage --lcov -i coverage -o coverage/lcov.info`; (d) threshold FAIL is strictly >12.00 (12.00 passes). Max CRAP now 12.00 OK, 3067 tests green.
