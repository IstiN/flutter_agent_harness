# Note: n_0978_b95d

flutter_agent_harness runs a WIP auto-save watcher that commits the working tree every ~5 min ("gh-XXXX WIP auto-save <timestamp>" commits, author AI Teammate). An abandoned mid-merge tree therefore gets AUTO-COMMITTED with literal conflict markers — this is how gh-1049's PR branch (ai/gh-1049) ended up with `<<<<<<< HEAD` markers inside test/integration/subagent_integration_test.dart, fa_cli_integration_test.dart, test/cli/tui_renderer_pty_test.dart and memory/.gitattributes (5 CI legs red: static gates parse errors, core shard, hostile-env, both PTY shards). Resolution shape: Dart files take the HEAD (PR) side; memory/.gitattributes takes origin/main's version (keeps both plural+singular merge=union drivers). Guard now in tree: test/conflict_markers_reg_test.dart (default suite) greps lib/bin/test/memory for committed markers.
