# Note: n_0980_f05c

gh-1192 design decisions (release-flow race hardening): (1) daily-publish pubdev verify logic extracted to scripts/verify_pubdev_release.sh with new status=release-in-flight — tag exists+(no run yet OR run queued/in_progress)+tag age<900s grace (RELEASE_FLIGHT_GRACE_SECS) -> neutral skip; run queued/in_progress skips REGARDLESS of age (E1 status governs); no run + age>=grace keeps byte-identical ::error:: text (AC2); tag-not-cut-yet keyed on bump-commit age on origin/main with 3600s horizon (TAG_CUT_GRACE_SECS, matches auto_release.sh wedge threshold). (2) tag_release.sh resolves BUMP_SHA (validated by exact subject 'chore(release): v<ver>' + pubspec version match, else grep origin/main --fixed-strings), refuses to tag a moving HEAD, git checkout --detach to the bump sha so release notes read the tagged tree; ci.yml release-tag passes BUMP_SHA=${{ github.event.head_commit.id || github.sha }}. Tests in test/release_flow_race_test.dart follow release_hygiene_test.dart fixture style (bare origin + stubbed gh/curl + pass-through git shim because session PATH has git-push-guard shim).
