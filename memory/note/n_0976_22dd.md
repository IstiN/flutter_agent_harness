# Note: n_0976_22dd

fa TUI boot perf (issue #503 follow-up, PR #672): the pre-run `_pending` drain in FaTuiController.run() is the boot hotspot for marathon sessions — per-writeln OutputMsgs each pay a TranscriptMarkdown sync. sendOutput must coalesce via the text buffer pre-run (flushed once at drain). Measure boot phases with sync stderr markers, NOT _logDiagnostic: fa.log appends are unawaited and race with other fa processes' writes, so marker lines get lost and timestamps mislead.
