# Note: n_1018_80a7

flutter_app golden baselines (test/golden/goldens/*.png) are captured only on the pinned macOS release runner with Flutter 3.47.4 (nightly pins it; ci.yml ubuntu shards exclude goldens). A linux dev host CANNOT reproduce them — even untouched baselines like setup_first_run_phone.png fail pixel-diff locally on the pinned SDK clone. After UI changes: restore/delete PNGs to match the widget surface, run `python3 scripts/check_goldens.py --quick` (orphan/existence gate), and leave the actual `flutter test test/golden --update-goldens` re-bake to the release flow; committing locally rendered PNGs breaks the macOS leg. Also: the agent's own session exports FA_PROVIDERS_QUEUE, which makes flutter_app test/providers_queue_writer_io_test.dart fail with 'FA_PROVIDERS_QUEUE env wins' — run with `env -u FA_PROVIDERS_QUEUE` to verify.
