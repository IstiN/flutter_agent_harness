# Note: n_0993_773e

fa repo: builtin-tool schema text is a token budget, not free prose — the mid-turn over-window guard (agent_loop.dart) prices `estimateRequestOverheadTokens` = (systemPrompt + Σ per-tool (name + description + jsonEncode(parameters))) / 4 against the model window, and `test/cli/agent_cli_over_window_test.dart` / `agent_cli_headless_over_window_test.dart` fixtures sit within ~25 tokens of the 12k edge. Adding ~50+ chars net to any tool description/parameter flips the fixture's request count (guard fires pre-send → compaction requests inflate stream.calls). Rule: when touching builtin tool schemas, keep the description+params delta net ≈ zero vs merge base (compress existing wording to pay for new properties), then run both over-window test files. Non-obvious: a same-size NEUTRAL wording change can pass while a structured property addition fails. [#note,#source_agent,prompt-budget,gotcha,testing]
