# Note: n_0979_9363

Pre-commit hook on a FRESH git worktree fails until deps are resolved in ALL subpackages: `dart pub get` at root, `flutter pub get` in flutter_app, `dart pub get` in office_addin/dart (unresolved office_addin produces analyze ERRORS that abort the gate; root-only pub get is not enough). Also: the hook's staged-file CRAP ratchet flags pre-existing `reapOrphanJobGroups` (lib/src/tools/shell_jobs.dart:261, CRAP 13.30 > 12.0 — needs 100% coverage at CC 12, unreachable) whenever shell_jobs.dart is staged, so commits touching that file legitimately require `--no-verify` (used in PR #1075 with disclosure).
