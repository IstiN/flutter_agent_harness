# Note: n_0998_2f2d

Running test/cli in explicit file-list batches (workaround for the pre-existing tui_prototype_snapshot native crash): (1) build the list from `*_test.dart` only — `ls test/cli/*.dart` drags in support files (agent_cli_test_support.dart, tui_render_harness.dart, and test/site_test_support.dart for the trees-after-cli list) which "fail to load" (Missing `main`) and are counted as the run's "1 failed" by dart test, though no real test failed; (2) NEVER run two dart test batches concurrently on this runner — wall-clock perf tests (wrap_ansi_line_perf_test.dart, <100ms budget) fail under CPU contention (measured 138ms) and pass solo right after; re-run any perf-class failure solo before treating it as real.
