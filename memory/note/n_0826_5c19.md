# Note: n_0826_5c19

Guided-flow конвенция в CLI: подсказка вида «(empty = X)» означает, что пустой ввод оставляет дефолт X; промпты не должны использовать слово 'default' как значение, иначе Enter буквально подставляет строку 'default'.
