# Note: n_0975_1da2

yoloit `yolochat:terminal --panel <name|id>` resolves the panel ambiguously — sending to "Goal Builder" (or even its exact panel id) actually typed into the "Support" terminal panel, which was running a live fa TUI, so the text landed as user input in that session. For automated terminal work prefer `script -q /tmp/x.log <cmd> &` PTYs or yoloit board.run panels, and always verify with `terminal:output`/`ps` that the command landed in the intended panel.
