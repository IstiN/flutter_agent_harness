# Note: n_0627_4704

Operational insight: the agent's own redaction pipeline masks its own display (filenames like id_rsa, REDACTED markers), so when writing test fixtures with secret-like bytes, extract real bytes via escaped dumps (e.g. codeUnits) instead of copy-pasting from masked output.
