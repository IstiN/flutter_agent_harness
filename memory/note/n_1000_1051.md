# Note: n_1000_1051

Workflow convention (gh-1600, 2026-10-17): the macOS publish legs' mirror-checkout MUST stay an INLINE `run:` script in build-mobile.yml/build-macos.yml — NEVER a local composite action (`uses: ./.github/actions/...`). Rationale: local `./` actions resolve against $GITHUB_WORKSPACE AT STEP TIME; on the persistent self-hosted runners that workspace holds the PREVIOUS run's tree (or nothing), and the checkout step is exactly what materializes it — a local action is missing on the first post-merge run and silently stale afterwards. Other conventions from the same fix: (1) self-hosted macOS-only jobs pin `runs-on: [self-hosted, macos-m5]` (fa-m5-1's unique registration label; the generic `[self-hosted, macOS, ARM64]` list also matches the Linux self-hosted box — the gh-1600 routing bug); (2) bench-harbor writes harbor output to `$RUNNER_TEMP/bench/jobs`, never the workspace, and tears shard docker containers down before rm (its cleanup step must declare its own ENV_TYPE — step-scoped env from the harbor-run step is invisible and `set -u` kills an always() step); (3) CI workflow-shape regressions are pinned by static tests parsing the workflow YAML (test/workflow_selfhosted_legs_test.dart pattern: workflow_fetch_shape_guard_test.dart / release_hygiene_test.dart precedent).
