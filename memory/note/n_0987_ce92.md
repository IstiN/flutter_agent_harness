# Note: n_0987_ce92

flutter_app/pubspec.lock is COMMITTED and enforced since gh-1265 (#1268, 2026-10-05): every workflow's flutter_app pub-get runs `flutter pub get --enforce-lockfile` (root, packages/*, office_addin lockfiles stay uncommitted/ignored). The fa-release-bot's `chore(release): vN` bumps root pubspec.yaml + flutter_app/pubspec.yaml but does NOT regenerate flutter_app/pubspec.lock — a version bump without `cd flutter_app && flutter pub get` + commit makes EVERY flutter_app CI leg (analyze, test shards 0-1, PTY screenshots, macOS/web/Android/iOS debug builds) exit 1 at pub get with "Unable to satisfy `pubspec.yaml` using `pubspec.lock`". RED/GREEN pinned by test/nightly_desktop_leg_guard_test.dart ("lockfile is in sync with the current package versions", gh-1265 AC2 REG guard). Fix = regenerate the lockfile, one-line version diff.
