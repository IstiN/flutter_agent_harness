# Note: n_0857_b707

In flutter_app, dartify()/jsonDecode nested maps reify as Map<Object?, Object?>; casts like `is Map<String, dynamic>` fail on them, and regression tests must feed real jsonDecode-shaped (<Object?, Object?>) literals to be non-vacuous.
