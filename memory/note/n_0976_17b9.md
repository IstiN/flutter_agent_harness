# Note: n_0976_17b9

gh-970 fix (branch ai/gh-970): subagent tool-call IDENTITY is zone-scoped — TaskExecutor.runSpawn/resumeChild publish the running child id via runWithSubagentScope (lib/src/task/subagent_scope.dart, same zone pattern as the yield token) because the executor's shared _currentSubagentIds stack names the LAST-STARTED child under concurrency, which used to mislabel reply/agent_message sender envelopes. schedule_message takes a senderMailbox override (hosts wire it from activeSubagentId()); ScheduledMessageQueue._deliveryTarget delivers self-addressed records naming <prefix>/<childId> as recorded instead of re-addressing to main, and SubagentManager.wakeChildrenWithPendingMail + CLI wakeChild wiring resume completed/idle children whose inbox received a reminder (the monitor-recurrence fix). Note: this runner exports FA_PROVIDERS_QUEUE, which makes 3 test/cli/providers_queue_editor_test.dart cases fail by design (env-wins semantics) — run them with `env -u FA_PROVIDERS_QUEUE`.
