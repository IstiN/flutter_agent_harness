# Note: n_0899_3bd7

Branded Chrome >= 137 ignores --load-extension, so extension e2e tests use Chrome for Testing installed at ~/.cache/fa-cft via `npx @puppeteer/browsers install chrome@stable --path ~/.cache/fa-cft`.
