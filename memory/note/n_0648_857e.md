# Note: n_0648_857e

Multiple agents (support, pr_review, goal_builder, feature agents) work concurrently in the same ~/git/flutter_agent working tree. Before shared-tree actions: check `git status` for others' uncommitted files and never stash/checkout/rebase over them; coordinate via agent_message to the support session in agent_directory. When the remote moved, push feature commits via a detached temp worktree (worktree add --detach /tmp/x origin/main + cherry-pick + push), then `git fetch && git reset origin/main` (mixed) locally and re-apply others' saved diffs.
