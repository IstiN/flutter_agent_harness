# Note: n_0987_884f

dmtools GitHub MCP tools name the owner/repo params `workspace` (owner/org) and `repository` (repo name), not `owner`/`repo`; IDs like runId/jobId are strings. Example: dmtools github_get_workflow_run_jobs --data '{"workspace":"IstiN","repository":"flutter_agent_harness","runId":"37239324226"}'. github_get_job_logs can return empty output for a valid job — use github_get_workflow_run_logs (whole run, all job logs concatenated with `--- N_Job name.txt ---` headers) instead.
