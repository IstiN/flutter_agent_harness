# Note: n_0992_4cd2

Running `dart test` from inside an fa harness session (this CI runner workspace) leaks the session's own FA_* env into spawned `fa` children (FA_LOG_FILE, FA_PROVIDERS_QUEUE, FA_PROVIDER_CONFIG, FA_PROVIDER_TYPE, FA_SESSION_ROOT, FA_SESSION_NAME) — integration-tagged tests that spawn the CLI (headless_log_file_test, backend_mode_cli_test, headless_tools_flag_test, yolo_rm_critical_e2e_test, …) fail on assertions like "does not contain 'plain reply'" purely from that leak. CI legs run those under a clean env, so they are green there. Local fix: prefix the run with `env -u FA_LOG_FILE -u FA_PROVIDERS_QUEUE -u FA_PROVIDER_CONFIG -u FA_PROVIDER_TYPE -u FA_SESSION_ROOT -u FA_SESSION_NAME`.
