# Note: n_0823_4a9b

Repo prompting principle (owner directive, issue #81): in compaction/checkpoint/handoff prompts NEVER use the word 'summary' or cognates ('summarize', 'concise overview', 'digest') — they prime the model to cut important information (root cause of the open-requests decay incident). Use lossless-handoff vocabulary instead: 'preserve', 'carry over verbatim', 'handoff', 'checkpoint', 'complete record'. Applies to prompts/compaction/*, branch-checkpoint prompts, and any future prompt in that family; review PRs touching these prompts for forbidden wording.
