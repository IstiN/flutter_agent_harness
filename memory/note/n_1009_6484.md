# Note: n_1009_6484

flutter_agent_harness repo gates that bite new code: (1) lib files must stay ≤2800 lines — `crap4dart.yaml` loc gate (add new CLI state code as a `part of 'agent_cli.dart'` part file, e.g. provider_model_coherence.dart, when provider_commands.dart fills up); (2) CRAP ratchet threshold 12.0 — keep per-method cyclomatic complexity ≤12 and cover every branch; (3) the similarity gate hard-fails on NEW file pairs with jaccard ≥0.5 (8-token shingles, .crap-baseline.json only shrinks) — never fork a test file's scaffolding wholesale; (4) `dart analyze lib test` must be issue-free (lints are fatal, office_addin/ errors are pre-existing and out of scope); (5) `dart format` is enforced. The harness auto-commits WIP snapshots every 5 min as "gh-NNNN WIP auto-save" — git status can be clean even mid-work; check `git log origin/main..HEAD` for the real state.
