# Note: n_1007_c527

flutter_agent_harness: adding a top-level config section requires BOTH lib/src/config/config_service.dart (configTopLevelKeys + _sectionValidators + optionally applicationNote) AND a yaml fence under a `## ` heading in prompts/skills/self-settings/SKILL.md — test/config/documented_keys_sweep_test.dart fails with "schema keys the skill never documents" otherwise. The CliConfig field/parse/render/copyWith/backstop edits alone are not enough.
