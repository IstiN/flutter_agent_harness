# Note: n_0466_66ae

CORRECTION (2026-09-02, official `copilot login --help` / GitHub Copilot CLI 1.0.82): supported Copilot credential types are fine-grained PATs (github_pat_…, v2) WITH the "Copilot Requests" permission, plus OAuth tokens (Copilot CLI app, gh app) — classic PATs (ghp_…) are NOT supported by Copilot at all. COPILOT_GITHUB_TOKEN is a first-class env var of the official CLI (precedence: COPILOT_GITHUB_TOKEN → GH_TOKEN → GITHUB_TOKEN). The exchange (api.github.com/copilot_internal/v2/token) hides missing Copilot access behind HTTP 404 — a github_pat_ without the Copilot Requests permission 404s (verified live with the keychain token; it also 401s on api.epam.ghe.com since it was issued on github.com). fa 0.1.280: paste accepts github_pat_ with a permission hint, warns+re-asks on ghp_, 404 message names the missing permission. This supersedes the 0.1.278-era note that claimed the opposite.
