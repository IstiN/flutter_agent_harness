# Note: n_0575_13a3

Fa widget state-sync: board tile and fullscreen app run separate JsAppEngine instances; they share state via a storage broadcast bus in flutter_app/lib/apps/js_app_engine.dart — every jsr.storage.set broadcasts a reserved 'state.sync' event {appId,key,value,writer} to sibling engines of the same app id, plus a post-start drift replay (writer:'boot') healing writes that landed during boot. Widgets keep state under reserved '__state' storage key {v,rev,writer,running,endsAt,remaining,mode,completed}; wall-clock endsAt is the countdown truth; protocol doc: fa_widgets/docs/state-sync.md. A 1x1 launcher tile override renders icon-only and boots no engine (LauncherLayoutStore.minTileWidth=1, JsTileWidgetInfo.minWidthCells=1).
