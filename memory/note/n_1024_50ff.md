# Note: n_1024_50ff

fa_ui owner-pass conventions (feat/fa2-ui-redesign, commits 5dfa1c4acb + f1d6d65859): (1) composer send/stop is a 40x32 solid-accent OVAL (ClipOval over ColoredBox palette.indigo, Icons.send_rounded 21pt, no glass/border/shadow) — key faChatComposerSendButton; (2) composer inset contract: 12px field-left + 10px icon-to-text gap (row padding LTRB(12,2,12,2) unified across modes, InputDecorator contentPadding horizontal 10) — pinned by the AC5 test in chat_composer_ergonomics_test.dart; (3) FaPaneResizeHandle (packages/fa_ui/lib/src/widgets/pane_resize_handle.dart) is THE shared pane-divider widget: hit surface (key faPaneResizeHandleHitSurface) 16px wide CENTERED on the panel edge, 3x36 hairline grip → accent .8 on hover; callers position it so grip-center == panel edge (sidebar: left: sidebarWidth - 16 — the card edge is at sidebarWidth - 8; files slot: left: -8 with Stack clipBehavior none, outside the reveal ClipRect); (4) transcript bubble body = theme bodyMedium - 1 notch (fa2 glass 15→14, legacy 14→13) inside chat_message_tile._bubbleContainer; explicit messageFontSize (ChatTextScope) always wins.
