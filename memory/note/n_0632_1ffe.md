# Note: n_0632_1ffe

jsr's native router keys live engines by `instanceId ?? widgetId`, so hosts MUST pass a unique JsRuntimeConfig.instanceId per engine instance — otherwise tile/fullscreen engines of the same widget collide and one dispose kills the shared route, freezing the survivor (render/storage drops).
