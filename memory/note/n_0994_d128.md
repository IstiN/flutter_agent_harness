# Note: n_0994_d128

flutter_app's engine-dependent tests (test/apps/**, gated by native_test_guard.dart's quickJsBridgeAvailable) CAN run on a bare Linux CI runner: flutter_js quickjs/ffi.dart honors LIBQUICKJSC_TEST_PATH when FLUTTER_TEST=true. Set LIBQUICKJSC_TEST_PATH=<pub-cache>/git/flutter_js-*/linux/shared/libquickjs_c_bridge_plugin.so (the .so ships inside the flutter_js git package, not on the loader path). Without it those suites silently SKIP — a fix to js_app_view/js_app_engine can look green while its behavioral coverage never ran.
