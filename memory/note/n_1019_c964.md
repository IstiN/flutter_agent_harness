# Note: n_1019_c964

flutter_agent_harness workflow-lint test gotcha (gh-2042 rework, pr-2045): writing static GitHub Actions lints in Dart tests, `${{ inputs.tag }}` inside a normal single-quoted Dart string is parsed as interpolation (a set literal `{inputs.tag}`) and both breaks compilation and gets mangled by `dart format` (which formats interpolation expressions, eating the spaces) — write the expected `${{ ... }}` literals as RAW strings (r'DISPATCH_TAG: ${{ inputs.tag }}'). Same for reason texts quoting `$VAR`. Also: the repo has NO core.hooksPath in agent checkouts (scripts/pre-commit not installed), so `dart format` self-heal does NOT run on commit — run `dart format <changed .dart files>` explicitly before committing, since PR-authored test files can arrive unformatted and the release-drift suite writes repo-root residue only when FA_DRIFT_DETAILS is unset (now pinned hermetic in test/release_drift_check_test.dart).
