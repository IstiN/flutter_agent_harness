# Note: n_0629_a5fe

GitHub НЕ запускает pull_request-workflows на CONFLICTING PR: гейты бегут против prospective merge-коммита, которого нет при конфликте. Симптом: ноль runs по ветке, только CodeQL default-setup; close/reopen и re-trigger коммиты не помогают. Fix: ребейз. Встречалось на PR #26 и #33 в IstiN/flutter_agent_harness. workflow_dispatch на ci.yml добавлен (7a57beaf) как ручной обход, но он берёт workflow-определение с target ref — работает только после ребейза.
