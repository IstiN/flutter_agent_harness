# Note: n_0464_5b25

GitHub Copilot's token exchange (GET api.github.com/copilot_internal/v2/token) returns HTTP 404 for fine-grained PATs (github_pat_ prefix) — only classic PATs (ghp_) and OAuth tokens (gho_/ghu_) work. GET api.github.com/user ACCEPTS fine-grained PATs, so the /provider copilot paste flow used to pass (login resolved) and fail later with a bare 404 + silent empty /models. Fixed in fa 0.1.278: paste step rejects github_pat_ immediately and re-asks, exchange short-circuits the token type, connect probes the exchange and prints the failure, 404 message names both causes (token type / no Copilot plan). The pinned VS Code client id Iv1.b507a08c87ecfe98 device flow was re-verified working 2026-09-02 (Phase-0 endpointDisabled 404 no longer reproduces).
