# Note: n_0014

TUI mouse mode is now auto-detected at startup (TuiMouseMode.auto): it captures the mouse for 500ms and keeps capture only if a wheel event arrives; can be forced with FA_TUI_MOUSE=1 (capture) or FA_TUI_MOUSE=0 (native selection), and toggled at runtime with the `/mouse` slash-command.
