# Note: n_0981_0bfb

Running `dart test` inside an fa agent session fails test/cli/providers_queue_editor_test.dart (3 tests: "FA_PROVIDERS_QUEUE env wins over any file queue...") because the harness itself exports FA_PROVIDERS_QUEUE into the session env the tests inherit. Reproduced on clean HEAD (pre-existing, not change-related). Run the suite with `env -u FA_PROVIDERS_QUEUE dart test ...` when verifying in-session.
