# Note: n_0839_b0f7

DAP hub connections in the fa CLI require DAP_MASTER_SECRET as a kill switch; without it the hub plugin stays silent and hub peers don't appear in agent_directory. Local hub doesn't validate the secret's content; session-only secrets don't persist across sessions.
