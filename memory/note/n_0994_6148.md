# Note: n_0994_6148

gh-1446 TUI chrome diet gotchas: (1) the herdr detection manifest parser (test/integration/herdr_detection_test.dart _Gate.inline) rejects brace quantifiers — regexes in docs/integrations/herdr/fa.toml must never contain {n,m}; (2) FaThemeController.reset() does NOT restore the symbol preset — tests that switchSymbols() must addTearDown(() => switchSymbols('unicode')) or later groups in the file see nerd glyphs; (3) the brand zone geometry is `>_` + 1-cell frame + `Fa` (idle frame cell = space → `>_ Fa`, running `>_⠋Fa`) — the ticket's `>_⠋ Fa` typography is loose; the invariant is the constant Fa column; (4) pty_resume_equivalence_test strips live running tool cards by glyph class — a status-glyph change must update that regex (derives from sym() now).
