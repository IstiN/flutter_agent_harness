# Note: n_0752_2c42

Boot-race fix in agent_main: explicit boot keys persist to chrome.storage and _ensureHost tracks the last explicit boot config (last-explicit-wins) so an auto-boot storage snapshot can never silently revert approvalMode to always-ask — this was the root cause of the CI e2e flakiness.
