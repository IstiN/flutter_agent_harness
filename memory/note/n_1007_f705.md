# Note: n_1007_f705

Running this repo's integration tests from INSIDE an fa agent session makes ~11 integration legs fail (backend_mode_cli, headless_tools_flag, yolo_rm_critical_e2e, headless_log_file): spawned `fa` sessions inherit the agent's FA_PROVIDERS_QUEUE / FA_LOG_FILE / FA_PROVIDER_CONFIG env and hit the real provider instead of the test's scripted one (timeouts, "No element", missing tool output). Fix when verifying: prefix with `env $(env | grep -oE "^(FA|FAH)[A-Z_]*" | sed 's/^/-u /') dart test ...`. Also pre-existing on this runner: test/browser_ext/ always fails (Chrome service worker needs DBus) and test/integration/composer_tui_grid_pty_test.dart "grid integrity mid-run at 100x40" is a render-timing flake — both fail on clean trees too (verify with `git worktree add /tmp/x <base>`).
