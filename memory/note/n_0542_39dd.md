# Note: n_0542_39dd

CPU storm (idle fa burning 60-90% in waves): root cause = fah_hub_client HubClient.defaultBackoff shift overflow — `1 << (attempt - 1)` is negative at attempt 64 and ZERO at 65+, bypassing the 30s cap → zero-delay tight reconnect loop to the dead default hub ws://127.0.0.1:8787 (observed _reconnectAttempt = 69.7M via vm_service). FIXED and PUBLISHED as `fa_hub_client 0.2.8` on pub.dev (the fah_hub_client name is owned by another pub.dev account; IstiN published the MIT code under the new name; repo github.com/IstiN/fa_hub_client, tag v0.2.8; PR #4 to the original repo pending). flutter_agent depends on hosted fa_hub_client ^0.2.8 (commit 958d48d5). NOTE: package 0.2.6+ also made the hub plugin INERT without DAP_MASTER_SECRET — fa hub/DAP tests inject a test master secret. Local repo path: ~/git/fah_hub_client (working copy of the IstiN fork).
