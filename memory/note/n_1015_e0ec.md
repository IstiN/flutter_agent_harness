# Note: n_1015_e0ec

ubuntu-latest CI runners now ship uutils-coreutils as /usr/bin/sleep: it is a multi-call binary dispatching on argv[0], so any test fixture that COPIES the sleep binary under another name (e.g. bash_self_defense_test.dart's fa_kl_271 victim) dies instantly with "coreutils: unknown program '<name>'". Use an argv0-agnostic binary instead (/bin/sh -c 'read _' blocks on stdin forever). First bit 2026-10-28: PR #1942 validation run 40690203051, Hostile ambient env leg, killall --signal TERM test rc=1 (red 2/3 deterministic).
