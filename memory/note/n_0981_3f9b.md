# Note: n_0981_3f9b

PR-rework landmine (gh-1054, CI-red on 1dd40fe1): a "merge origin/main into <branch>" resolution that takes the branch side of a file WHOLESALE silently reverts main-side work that landed after the branch forked — the branch kept compiling its own side while main's call sites (merged cleanly from main in OTHER files) reference what was dropped, so the shared core package stops compiling and every dependent CI job reddens at once (core test shards whose files import it, fa_ui, iOS build). Detection recipe: (1) `dart pub get` then `dart analyze` — resolution-stale checkouts report thousands of phantom uri_does_not_exist errors before the refresh; (2) diff the PR head against the NEWEST main (`git diff <main-tip> HEAD`) and require every PR-touched file's delta to be feature-shaped additions only — agent.dart showed -97 lines of reverts (#1085 onRunWatchdogPaused/watchdog-suspension + RunIdleWatchdogFire typed cancel); (3) reconstruct the correct resolution as `git checkout <main-tip> -- <file>` + re-apply only the feature's own deltas (verify with `git diff <feature-commit> -- <file>` = main-side changes only). Also: adding a sealed-hierarchy subtype (AgentEvent) requires classifying it in lib/src/wire/wire_protocol.dart's exhaustive encodeEvent/_kindOf switches + _eventDecoders + golden fixture + nativeEventFor, and test/wire/wire_adapter_test.dart's kind mirror — the analyzer lists them all as non_exhaustive_switch_expression.
