# Note: n_0974_1e2b

Running the integration/PTY suites on the ai-teammate runner requires unsetting the ambient provider env (FA_PROVIDERS_QUEUE, FA_PROVIDER_CONFIG, FA_PROVIDER_TYPE, FA_LOG_FILE, FAH_PROVIDER, FAH_MODEL, FAH_SESSION_*, FA_SESSION_*) first: spawned `fa` children inherit them and hijack provider selection / log destinations — 15 integration tests fail purely from this (the #675 hostile-env class; GitHub-hosted CI runners don't export these). Also: the dap_tui_menu_test.dart hub-hello test times out deterministically on this box even with a clean env (passes on CI's ubuntu arm64 leg) — do not chase it locally.
