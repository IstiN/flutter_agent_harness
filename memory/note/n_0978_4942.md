# Note: n_0978_4942

On this Mac, `flutter test` runs wedge/fail for two recurring reasons: (1) week-old zombie `flutter_tools test` processes at 0% CPU hold artifact locks — check `ps -eo pid,etime,%cpu,comm | grep flutter` and kill stale ones before long runs; (2) the interactive shell's soft FD limit is 256, which kills big test runs with "too many open files" — prefix long test/coverage/commit commands with `ulimit -n 10240`. Also: piping `git commit` through `| tail` masks the pre-commit hook's exit code (commit silently missing afterwards) — always capture COMMIT_EXIT explicitly.
