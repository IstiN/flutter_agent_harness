# Note: n_0798_650a

Dart gotcha: awaiting StreamController.close() hangs forever when the stream has a paused listener (e.g. an async-package StreamQueue between next() calls pauses the subscription, blocking delivery of the done event). Fix: fire unawaited(controller.close()) — queued events still flush. Hit in dap_hub's RawWsConnection._finish, which made WebSocket codec tests time out in tearDown.
