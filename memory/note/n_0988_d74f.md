# Note: n_0988_d74f

This checkout has a PARALLEL WIP AUTO-SAVE process that commits working-tree changes every ~5 minutes as "gh-<ticket> WIP auto-save <timestamp>" commits (author AI Teammate). Consequence: files you edited can show as CLEAN in git status because HEAD moved, and git stash push reports "No local changes to save". To diff/revert your own in-flight work use explicit revisions (git checkout <sha> -- path, git diff <sha> -- path), not stash. See gh-1274 PR note: "committed by a parallel env process, not by the fix". [#git,gotcha,workflow]
