# Note: n_0992_1b0f

`dart test test/cli/tui_prototype_snapshot_test.dart` (and any full `dart test` run that reaches it) aborts at teardown on this Ubuntu runner with `malloc_consolidate(): unaligned fastbin chunk detected` → SIGABRT (exit 134) AFTER all 5 tests pass. Reproduces byte-for-byte on a pristine origin/main worktree — pre-existing platform/glibc issue, not caused by any branch work; does not occur in CI legs. The abort kills the dart test process mid-suite (no summary line), so a `dart test | tail` pipe loses the results of every queued-after file — run the remaining trees explicitly instead.
