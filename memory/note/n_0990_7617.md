# Note: n_0990_7617

Headless full-boot TUI tests (AgentCli with useTui: true) MUST pass `tuiProgramHooks: TuiProgramHooks(input: keys.stream, output: frames, width:, height:)` in AgentCliConfig — without it the dart_tui program writes to FakeCliIO's stdout and the _FrameSink stays empty forever, so every frames.text waitFor spins to timeout. Working twins: agent_hub_overlay_guard_test.dart, agent_cli_tui_sync_test.dart. Also anchor any injected waitingClock at DateTime.now(), never a pinned past date (overdue-timer storm starves the REPL loop).
