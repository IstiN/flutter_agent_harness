# Note: n_1030_a0cf

flutter_agent_harness ci-red ticket recovery protocol: a red release-TAG run (push event, refs/tags/v*) is recovered by `gh run rerun <run-id>` (full, not --failed, so the skipped release legs re-evaluate) — precedent gh-2182/v1.0.725 attempt 2 success with triggering_actor ai-teammate. The ci.yml Watchdog's never-rerun doctrine is scoped to PR-branch timeout legs only (its if-guard is pull_request-only). Ambient load-phase reds ("Failed to load X: Connection closed before full header was received", N passed/1 failed) = killed dart_test workers on degraded runners; same-SHA green on a main run proves it. 3 of the last 5 release tags red this way (725, 728, 729).
