# Note: n_0991_7997

Subagent board row spacing (gh-1415, lib/src/cli/subagent_board.dart): the state field is 4 cells — `run`/`wait` pad to `run `/`wait ` so the name follows after TWO spaces, but `done`/`fail` fill the field exactly so the name follows after ONE space (`✓ done boardwatch`). Test anchors must use `done\s+name` regexes, not a literal two-space gap. Related: dart_tui diff-renders changed cells only, so a 1 Hz in-place age tick writes just the digit cell to the PTY raw stream — never anchor a raw-stream assertion on the full re-rendered row; assert on the rendered screen instead.
