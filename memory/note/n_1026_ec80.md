# Note: n_1026_ec80

sqlite3 native-assets hook cache (gh-2072): the sqlite3 package's build hook downloads prebuilt binaries into `<consumer-root>/.dart_tool/hooks_runner/shared/sqlite3/build/download-<hash8-of-pinned-sha256>/<libraryFileName>` (empirically confirmed: download-0f947ebe = libsqlite3.x64.linux.so). Reuse = file exists + sha256 match; on mismatch it silently RE-DOWNLOADS. Release-asset naming: `libsqlite3.<abi>.<os>.{so,dylib}` EXCEPT windows which has NO lib prefix (`sqlite3.x64.windows.dll`). The prewarm fix lives in scripts/sqlite3_native_assets_prewarm.dart + .github/actions/sqlite3-native-assets-prewarm, guarded by test/ci_sqlite3_prewarm_guard_test.dart.
