# Note: n_0994_7469

This repo's dev-agent CI runner auto-commits WIP snapshots every ~5 minutes as "gh-<id> WIP auto-save <timestamp>" on the ai/gh-<id> branch. Mid-task, `git status`/`git diff` can therefore show files "missing" or already committed — check `git reflog` / the WIP commits before concluding work was lost. Also: `dart format` churns files last touched by an older SDK (e.g. test/compaction/compaction_test.dart was ~200 lines off current dart_style output) — restore-and-hand-edit instead of committing whole-file reformats of files you didn't functionally change. flutter_app tests need a local gitignored `.env` file (pubspec declares it as an asset; `echo "" > flutter_app/.env` unblocks the leg in a fresh checkout).
