# Note: n_0285

API keys are stored by name convention FA_KEY_API_<HOST>_<PROVIDER_NAME> (e.g. FA_KEY_API_MINIMAX_IO_MINIMAX) in env or macOS Keychain; MiniMax error status_code 1004 means missing/invalid Authorization key.
