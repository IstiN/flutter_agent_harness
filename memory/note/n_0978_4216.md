# Note: n_0978_4216

Running `dart test test/cli/` inside this agent environment fails 3 tests in test/cli/providers_queue_editor_test.dart ("FA_PROVIDERS_QUEUE env wins over any file queue") because the session env exports FA_PROVIDERS_QUEUE. Run with `env -u FA_PROVIDERS_QUEUE dart test ...` to get a green run. Full-suite runs also fail test/parity and test/uploads when other dart test processes run concurrently (timing-sensitive suites under CPU starvation) — run the full suite alone.
