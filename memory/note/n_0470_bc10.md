# Note: n_0470_bc10

GitHub Copilot auth (per official Copilot CLI 1.0.82 docs): fine-grained PATs (github_pat_) are supported ONLY with the 'Copilot Requests' permission, OAuth tokens (gho_/ghu_) work, and classic ghp_ tokens are NOT supported at all.
