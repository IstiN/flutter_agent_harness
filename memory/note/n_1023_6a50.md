# Note: n_1023_6a50

Fa macOS Impeller RE-ENABLED 2026-11-02 (commit 69368fd7b0, branch feat/fa2-ui-redesign): FLTEnableImpeller=true in flutter_app/macos/Runner/Info.plist. The earlier raster SIGSEGV mitigation (Impeller off → Skia) silently degraded ALL glass to flat fallbacks because liquid_glass_renderer's real glass AND liquid_glass_widgets' ProgressiveBlur shader path require Impeller shader filters (ImageFilter.isShaderFilterSupported). Smoke-run on macOS MetalSDF stable with the slimmer glass plane set (sidebar FaSurface + ProgressiveBlur chrome). If the raster crash returns, FLTEnableImpeller is the first switch to flip back. Styleguide rule (user directive): the app must use ready-made styleguide components (packages/fa_ui Fa* widgets) across all four FaVisualDirection themes (glass/nebula/graphite/porcelain) — glass direction gets real LiquidGlass, others get opaque fallbacks; hand-rolled translucent containers in messenger chrome are to be replaced by styleguide/library components (liquid_glass_widgets catalog is now a flutter_app dependency ^1.16.1).
