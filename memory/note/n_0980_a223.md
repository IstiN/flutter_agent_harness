# Note: n_0980_a223

Dev-write runners export hostile ambient env vars (FA_PROVIDER_TYPE, FA_PROVIDER_CONFIG, FAH_PROVIDER, FA_PROVIDERS_QUEUE — the latter flipped queue-editor tests red on 2026-10-03). Per issue #675, tests must resolve through injected env seams, never Platform.environment; ci.yml's hostile-env job pins the known set — add newly discovered vars there. To replicate CI locally: run the full suite with those vars exported before trusting a green run.
