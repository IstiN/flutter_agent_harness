# Note: n_0353

kimi-for-coding поддерживает native tool calling хорошо (подтверждено пользователем 2026-08-30; ранняя заметка о "fake tool-call text" была ошибочной — тот сбой был из экспериментов по оптимизации контекста). Текущие роли в ~/.fah/config.yaml: default=k3-256k (ключ FA_KEY_API_KIMI_COM_KIMI_ME), smol и subagent = kimi-for-coding.
