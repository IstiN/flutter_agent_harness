# Note: n_0975_ebf8

CI-retrigger gotcha: when a bot (release/gardener flow) merges main into an open PR branch using GITHUB_TOKEN, the resulting push does NOT trigger ci.yml/browser-ext.yml — required checks (Quality gate, Headless Chrome suite) never report and the PR becomes unmergeable ("base branch policy prohibits the merge"). Fix: push an empty commit ("chore: retrigger CI") to the PR branch so the workflows fire.
