# Note: n_0944_aa8f

CodeMie with a dead SSO session silently 302-redirects to the login portal; both fetch and dart:io follow the redirect, so API calls return 200+text/html (or 200+JSON gateway error, or an empty event-stream) — sendProviderRequest in provider_common.dart rejects all three and emits the [[auth-expired:codemie]] marker.
