# Note: n_0576_6ac9

Cross-repo widget work convention: js_widget_runtime (jsr) widget changes go through the jsr agent via agent messaging (it implements, tests on QuickJS, refreshes tile-matrix goldens, pushes; its push triggers pub publish workflow). fa_widgets consumes jsr widgets by bumping the vendor/js_widget_runtime submodule pin; its main push rebuilds the rolling release (catalog.json + per-widget zips) and installed clean widgets auto-follow on launcher boot (autoUpdateCleanWidgets).
