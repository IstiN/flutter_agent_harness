# Note: n_1020_7144

On the Linux CI runner (Google Chrome 156 branded at /usr/bin/google-chrome), browser_ext/e2e specs all fail with ERR_BLOCKED_BY_CLIENT because branded Chrome >= 137 ignores --load-extension; run them with CHROME_PATH=$(which chromium) (unbranded Chromium 156) and they pass.
