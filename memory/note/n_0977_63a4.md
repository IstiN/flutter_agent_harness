# Note: n_0977_63a4

Factory dev-leg sessions (gh-<ticket> branches): the harness auto-commits in-progress work as 'gh-<key> WIP auto-save <timestamp>' commits every few minutes. Mid-task `git status` can show CLEAN even with unsaved edits — always `git log --oneline -3` before committing; if a WIP auto-save swallowed your change, stage any remaining bits and `git commit --amend` it into the real message instead of re-creating work. Also: the dmtools commit guard REJECTS closing keywords in commit messages (e.g. 'fix #975') — phrase as 'the #975 single-flow' or 'issue-#975'; closing keywords belong to the PR body only.
