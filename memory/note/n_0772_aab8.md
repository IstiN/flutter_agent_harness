# Note: n_0772_aab8

Release bot merges main into open PR branches using GITHUB_TOKEN; such pushes do NOT trigger ci.yml/browser-ext.yml, so required checks (Quality gates, Headless Chrome suite) never report and the PR becomes unmergeable ("base branch policy prohibits the merge"). Fix: push an empty commit ("chore: retrigger CI") to the PR branch.
