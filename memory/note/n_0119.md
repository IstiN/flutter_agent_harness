# Note: n_0119

Dynamic Dart code loading does not exist on iOS, so JS widgets must remain manifest artifacts and must never be modeled as FahPlugin implementations; FahPlugin (Dart, compiled in) and JS widgets are separate concepts joined only by one host bridge tool.
