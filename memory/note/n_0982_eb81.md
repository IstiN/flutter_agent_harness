# Note: n_0982_eb81

The same-file parallel edit race (lost exact-match edits in one batch) is a confirmed fa harness bug — issue #1083: agent_loop runs tool batches in PARALLEL by default (pi semantics, agent_loop.dart:1754-1787/1852+), no built-in tool sets executionMode (agent_tool.dart:55/74 optional), exact-match edit has no staleness guard (hashline TAG mode does). Fix contract: per-path mutation lock; until it lands, batch same-file edits strictly sequentially.
