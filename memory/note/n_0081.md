# Note: n_0081

fa CLI behavior: a bare `fa` launch ALWAYS creates a fresh empty session (_initializeSession in agent_cli.dart); there is NO auto-resume of the last active session. To continue history use `fa --session <name|id>` or `/resume` inside the REPL, or the app's attach view for a live session. Multiple concurrent agents therefore each start blank by design.
