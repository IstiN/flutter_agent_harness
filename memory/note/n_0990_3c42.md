# Note: n_0990_3c42

flutter_agent_harness rework gotcha (gh-1403 round, 2026-10-08): the WIP auto-save bot formats staged Dart files with a PRE-tall-style formatter before committing — its commit fbf142951 reformatted ~1853 unrelated lines of test/release_hygiene_test.dart from the repo's canonical tall style (Dart 3.13 `dart format`, which CI's setup-dart stable produces and which main's files satisfy) into short style, silently bloating the PR diff even though CI itself does NOT gate on format (no `dart format --set-exit-if-changed` in ci.yml; only scripts/pre-commit self-heals, and only for agents that run it). Recovery recipe that worked: when a rework wants a test concern OUT of a god-file, checkout the file from origin/main (if the net intent is "file returns byte-identical to main") instead of incrementally un-deleting, rewrite any new sibling file with tall-style content, settle with `dart format`, and let the bot commit+push — never force-push over the automation. Verify the final `git diff origin/main --stat` is feature-shaped only. Also: the bot can race you between `git add` and `git commit` ("nothing to commit" = check `git log` — your tree is already committed/pushed; content identical means done).
