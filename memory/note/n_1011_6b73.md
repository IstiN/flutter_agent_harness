# Note: n_1011_6b73

Web verification recipe (works on the ubuntu CI runner): compile a one-off dart2js probe of REAL production web code with `flutter/bin/cache/dart-sdk/bin/dart compile js /tmp/x/probe.dart -o probe.js --packages=flutter_app/.dart_tool/package_config.json -O4` (package:fa resolves via the app's package config; the probe file itself lives in /tmp), serve the dir with `python3 -m http.server`, and drive it with playwright from the preinstalled `/tmp/probe/pw/node_modules` (symlink as node_modules; `npx playwright` works but plain node ESM ignores NODE_PATH; browsers already in ~/.cache/ms-playwright). Negative control: `git show <oldrev>:path > path`, recompile, rerun — proves the probe detects the bug. Repo boot smoke: `scripts/web_boot_smoke.mjs` (needs the same node_modules symlink trick).
