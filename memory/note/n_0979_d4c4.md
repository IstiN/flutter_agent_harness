# Note: n_0979_d4c4

flutter_app AgentService tests: the default lightweight-ctor approval mode is ApprovalMode.write, which auto-DENIES unknown/custom tools ("The user denied the \"x\" tool call." as the tool result). Any test exercising tool execution must set service.approval.mode = ApprovalMode.yolo (see existing tool tests). This silently neutered agent_service_test.dart's over-window guard test for a while — it passed vacuously on a 37-char denial result until gh-1077 IT work exposed it.
