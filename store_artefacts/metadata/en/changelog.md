# Changelog

## [0.1.87] - 2026-07-26

- HomeKit: full smart-home control — homes, rooms, accessories, scenes, and any writable characteristic
- Fixed an empty-homes race right after granting Home access
- Shareable debug logs (Settings → Copy debug logs)
- Rename sessions from the sidebar
- Add arbitrary agent keys in Settings (saved to the Keychain)
- Approval mode (e.g. yolo) now persists between launches
- Calendar: recurring events, alarms, calendar picker, span and URL support
- Inline audio and video playback right in the chat
- Smoother thinking streams (deduplicated reasoning)
