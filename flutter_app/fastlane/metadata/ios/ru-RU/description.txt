Fa — это личный ИИ-агент на вашем телефоне и Mac. Общайтесь с любым OpenAI-совместимым провайдером, запускайте настоящего изолированного coding-агента, позвольте ему создавать мини-приложения для вас и генерируйте изображения, речь и музыку — с приватностью на первом месте: ваши ключи хранятся в Keychain.

ЛЮБОЙ ПРОВАЙДЕР, ВАШИ КЛЮЧИ
- OpenRouter, OpenAI, Anthropic, Google, Ollama — любой OpenAI-совместимый API
- Добавляйте своих провайдеров с собственным base URL и моделями
- Локальные модели (Gemma, WebLLM) для офлайн-чатов без ключей
- API-ключи остаются в Keychain iOS/macOS — не в конфигах, не в облаке

НАСТОЯЩИЙ АГЕНТ, А НЕ ПРОСТО ЧАТ
- Fa рассуждает открыто: наблюдайте ход мыслей, вызовы инструментов и результаты
- Изолированная песочница: shell, файловая система, git, Python, Lua, SQLite и JavaScript
- Читает, пишет и правит код; ищет в интернете; загружает страницы
- Уровни подтверждения держат под контролем каждую запись и команду

МИНИ-ПРИЛОЖЕНИЯ ПО ЗАПРОСУ
- Попросите Fa создать приложение — калькулятор, карты, заметки, трекеры — и оно появится в боковой панели
- Мини-приложения могут работать с календарём, контактами, устройствами HomeKit и данными Здоровья (с вашего разрешения)
- Продолжайте диалог с Fa прямо внутри приложения, чтобы его улучшать

ГЕНЕРАЦИЯ МЕДИА
- Генерация изображений прямо в чате
- Синтез речи и музыки с отдельными медиа-моделями для каждого слота
- Воспроизведение аудио и видео прямо в диалоге

ВАШИ ДАННЫЕ — ВАШЕ УСТРОЙСТВО
- Приватная аналитика: никакого текста сообщений, ключей и содержимого файлов — никогда
- Сессии хранятся локально, опционально — синхронизация через iCloud
- Переименовывайте сессии, ветвите диалоги, откатывайтесь к контрольным точкам

РАБОТАЙТЕ КАК УДОБНО
- Тёмная и светлая темы, русский и английский интерфейс
- iPhone, iPad и Mac — одно приложение, один агент
- Бесплатно и с открытым кодом: используйте свой ключ, платите только своему провайдеру

Fa — агент, который работает на вас: на вашем устройстве и по вашим правилам.
