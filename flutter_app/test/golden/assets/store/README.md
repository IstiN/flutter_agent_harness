# Store screenshot photo assets

Real photos used inside the App Store marketing screenshots generated by
`test/golden/store_screenshots_test.dart` (the "your own apps, built by
chat" story frames). They are test fixtures only — never shipped in the
app.

Source: loremflickr.com (real Flickr photos, photographer credit embedded
in each image corner). picsum.photos and upload.wikimedia.org were
geoblocked from the maintainer network at generation time (2026-07-27).

- `dashboard_wallpaper.jpg` — calm lake landscape ("lake, calm"),
  © ShebleyCL (CC). Stands in as the AI-generated wallpaper in the media
  frame (written into the sandbox as `generated/dashboard-wallpaper.png` —
  the app's `generate_image` tool tiles sniff `.png` paths, and the image
  codec decodes the JPEG bytes regardless of the file name).

The photo is 900x600 and well under 500 KB. Replace by downloading a new
photo at the same size and keeping the file name; the generator copies
these bytes into the in-memory sandbox, so no test code changes are
needed.
