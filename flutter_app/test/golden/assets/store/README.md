# Store screenshot photo assets

Real photos used inside the App Store marketing screenshots generated by
`test/golden/store_screenshots_test.dart` (the "Makar's week" story frames).
They are test fixtures only — never shipped in the app.

Source: loremflickr.com (real Flickr photos, photographer credit embedded
in each image corner). picsum.photos and upload.wikimedia.org were
geoblocked from the maintainer network at generation time (2026-07-27).

- `club_photo.jpg` — kids at an outdoor craft table ("children, park"),
  photo © Seattle Parks & Recreation. Used as the Saturday-club photo the
  parent shares in the chat frame.
- `birthday_card.png` — "Happy Birthday" balloons illustration
  ("balloons, colorful"), © Javcon117* (CC BY-SA), converted from JPEG to
  PNG because the app's `generate_image` tool tiles sniff `.png` paths.
  Stands in as the AI-generated birthday card in the chat frame.
- `week_header.jpg` — calm lake landscape ("lake, calm"),
  © ShebleyCL (CC). Header strip of the hand-built calendar week canvas.

All three are 900x600 and well under 500 KB (`birthday_card.png` is the
PNG transcode noted above). Replace by downloading a new photo at the same
size and keeping the file name; the generator copies these bytes into the
in-memory sandbox, so no test code changes are needed.
