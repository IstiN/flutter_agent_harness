Support — fa for Outlook

Installing

Sideload the add-in from its manifest: https://fa1.dev/outlook/manifest.xml

  • Outlook on the web: Settings → Integrate apps → Upload custom apps → “Add from a URL”, then paste the manifest URL.
  • Windows / Mac (classic Outlook): follow Microsoft’s sideload guide with the same manifest URL.

Troubleshooting

  • “host API unavailable” banner: the Office.js runtime did not load. Reload the taskpane; if it persists, the pane answers without mail tools.
  • Taskpane blank: make sure your network allows fa1.dev and the Office.js CDN.
  • Build a dev copy: bash scripts/build_office_addin.sh --dev produces a manifest pointed at https://localhost:8443.

Contact

Still stuck? Mail support@fa1.dev and include your Outlook host (web / Windows / Mac) and the version shown in the taskpane.
